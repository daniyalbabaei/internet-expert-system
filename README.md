# 📶 نت‌داکتر (NetDoctor) — نسخهٔ ۲.۰

> **سیستم خبرهٔ فارسی تشخیص و رفع قطعی اینترنت** — ویزارد تشخیص ۱۰ مرحله‌ای، کاملاً سمت کلاینت، بدون سرور، با موتور استنتاج قاعده‌محور (Rule-Based Expert System)

🔗 **نسخهٔ آنلاین (GitHub Pages):** https://daniyalbabaei.github.io/internet-expert-system/

---

## ✨ ویژگی‌ها

- 🧭 **ویزارد تشخیص ۱۰ مرحله‌ای** — از شناسایی محدودهٔ مشکل تا تاریخچه و زمینه؛ با نشانگر مرحله‌ها و نوار پیشرفت
- 🧠 **موتور استنتاج مبتنی بر قواعد** (Forward Chaining) با انتخاب قاعدهٔ برتر بر اساس درصد اطمینان
- 🗣 **سؤالات تطبیقی (Adaptive)** — فقط سؤال‌های مرتبط پرسیده می‌شود؛ مثلاً اگر همهٔ دستگاه‌ها قطع باشند، دیگر سراغ تست‌های تک‌سیستمی نمی‌رود
- 🛠 **راه‌حل گام‌به‌گام** همراه با دستورهای آمادهٔ قابل کپی (`ipconfig`, `netsh`, `ms-settings`, ...)
- 🧠 **سازوکار توضیح (Explanation Facility)** — «چرا این تشخیص؟» واقعیت‌های ورودی + قاعدهٔ فعال را نشان می‌دهد
- 🤔 **پیشنهاد تشخیص دوم** — اگر راه‌حل اصلی جواب نداد، سراغ احتمال بعدی بروید
- 📚 **پایگاه دانش قابل مرور** — ۲۳ تشخیص تخصصی، ۴۵ قاعدهٔ IF–THEN، ۲۶ سؤال تشخیصی، ۱۰ مرحله
- 🖨 **چاپ گزارش تشخیص** با استایل مخصوص چاپ
- 🇮🇷 **فارسی و راست‌چین** با فونت وزیرمتن + پوشش DNSهای داخلی (شکن، الکترو، ۴۰۳)
- 🔒 **کاملاً خصوصی** — هیچ داده‌ای به هیچ سروری ارسال نمی‌شود؛ همهٔ استنتاج داخل مرورگر انجام می‌شود
- 📱 ریسپانسیو و سازگار با موبایل

## 🔍 پوشش تشخیص‌ها (۲۳ مورد)

قطعی کلی ISP • خرابی روتر/DHCP مودم • شکست DHCP و آدرس APIPA • اشباع ظرفیت مودم • خرابی DNS • DNS دستی نامناسب • از کار افتادن آداپتور Wi-Fi و درایور WLAN • شکست احراز هویت Wi-Fi • خرابی پشتهٔ TCP/IP و Winsock • قطعی کابل/پورت LAN • خرابی خط تلفن ADSL • خرابی VPN/پروکسی • تداخل آنتی‌ویروس/فایروال • مشکل مرورگر (کش/افزونه) • کاهش سرعت • اتمام حجم/FAP • مشکل آنتن‌دهی TD-LTE/4G • تداخل کانال Wi-Fi • تأخیر بالا (لگ) • اتصال ناپایدار • هات‌اسپات موبایل • درایور بعد از آپدیت ویندوز • سلامت کامل شبکه (مشکل از مقصد) • برنامهٔ تعمیر کامل شبکه

## ➕ افزودن دانش جدید

موتور استنتاج هیچ تغییری لازم ندارد؛ کافی است در `kb.js`:

1. سؤال جدید به آرایهٔ `QUESTIONS` (با `stage` برای مرحلهٔ ویزارد و `cond` اختیاری برای نمایش تطبیقی)
2. گزارهٔ تشخیص جدید به شیء `DIAGNOSES` (با راه‌حل‌ها و دستورها)
3. قاعدهٔ جدید به آرایهٔ `RULES` (شرط‌ها + تشخیص + درصد اطمینان + دلیل)
