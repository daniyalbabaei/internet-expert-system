# 📶 نت‌داکتر (NetDoctor)

> **سیستم خبرهٔ فارسی تشخیص و رفع قطعی اینترنت** — کاملاً سمت کلاینت، بدون سرور، با موتور استنتاج قاعده‌محور (Rule-Based Expert System)

🔗 **نسخهٔ آنلاین (GitHub Pages):** https://daniyalbabaei.github.io/internet-expert-system/

---

## ✨ ویژگی‌ها

- 🧠 **موتور استنتاج مبتنی بر قواعد** (Forward Chaining) با انتخاب قاعدهٔ برتر بر اساس درصد اطمینان
- 🗣 **سؤالات تطبیقی (Adaptive)** — فقط سؤال‌های مرتبط پرسیده می‌شود؛ مثلاً اگر همهٔ دستگاه‌ها قطع باشند، دیگر سراغ تست‌های تک‌سیستمی نمی‌رود
- 🛠 **راه‌حل گام‌به‌گام** همراه با دستورهای آمادهٔ قابل کپی (`ipconfig`, `netsh`, `ms-settings`, ...)
- 🧠 **سازوکار توضیح (Explanation Facility)** — «چرا این تشخیص؟» واقعیت‌های ورودی + قاعدهٔ فعال را نشان می‌دهد
- 🤔 **پیشنهاد تشخیص دوم** — اگر راه‌حل اصلی جواب نداد، سراغ احتمال بعدی بروید
- 📚 **پایگاه دانش قابل مرور** — ۱۶ تشخیص تخصصی، ۲۱ قاعدهٔ IF–THEN، ۱۳ سؤال تشخیصی
- 🖨 **چاپ گزارش تشخیص** با استایل مخصوص چاپ
- 🇮🇷 **فارسی و راست‌چین** با فونت وزیرمتن + پوشش DNSهای داخلی (شکن، الکترو، ۴۰۳)
- 🔒 **کاملاً خصوصی** — هیچ داده‌ای به هیچ سروری ارسال نمی‌شود؛ همهٔ استنتاج داخل مرورگر انجام می‌شود
- 📱 ریسپانسیو و سازگار با موبایل

## 🧠 معماری سیستم خبره

```
کاربر ──پاسخ──▶ رابط کاربری تطبیقی
                    │
                    ▼
              واقعیت‌ها (Facts)
                    │
                    ▼
        ┌─── موتور استنتاج ───┐
        │  ارزیابی ۲۱ قاعده   │
        │  انتخاب قاعدهٔ برتر  │
        └─────────┬───────────┘
                  ▼
   تشخیص + درصد اطمینان + «چرا؟»
                  ▼
        راه‌حل گام‌به‌گام + دستورها
```

سه جزء کلاسیک سیستم خبره در این پروژه پیاده شده است:

| جزء | پیاده‌سازی | فایل |
|------|-----------|------|
| پایگاه دانش (Knowledge Base) | ۱۳ سؤال، ۱۶ گزارهٔ تشخیص، ۲۱ قاعده | `kb.js` |
| موتور استنتاج (Inference Engine) | Forward Chaining + Confidence | `app.js` |
| سازوکار توضیح (Explanation) | بخش «چرا این تشخیص؟» | `app.js` |

## 🔍 پوشش تشخیص‌ها

قطعی کلی ISP • خرابی روتر/DHCP مودم • شکست DHCP و آدرس APIPA • خرابی DNS • از کار افتادن آداپتور Wi-Fi و درایور WLAN • شکست احراز هویت Wi-Fi • خرابی پشتهٔ TCP/IP و Winsock • قطعی کابل/پورت LAN • خرابی VPN/پروکسی • مشکل مرورگر (کش/افزونه) • کاهش سرعت • اتصال ناپایدار • هات‌اسپات موبایل • درایور بعد از آپدیت ویندوز • سلامت کامل شبکه (مشکل از مقصد) • برنامهٔ تعمیر کامل شبکه

## ➕ افزودن دانش جدید

موتور استنتاج هیچ تغییری لازم ندارد؛ کافی است در `kb.js`:

1. سؤال جدید به آرایهٔ `QUESTIONS` (با `cond` اختیاری برای نمایش تطبیقی)
2. گزارهٔ تشخیص جدید به شیء `DIAGNOSES` (با راه‌حل‌ها و دستورها)
3. قاعدهٔ جدید به آرایهٔ `RULES` (شرط‌ها + تشخیص + درصد اطمینان + دلیل)
